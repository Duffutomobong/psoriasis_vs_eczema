# Psoriasis vs Eczema — Binary Image Classification

**Course:** GET 324 — Laboratory Exercise 10 (Mini-Project)
**Task:** Cloud Computing and AI Model Deployment for Engineering Applications
**Assigned classification task:** Psoriasis vs Eczema

## 1. Project Overview

This project designs, trains, evaluates, and deploys a Convolutional Neural
Network (CNN) — using MobileNetV2 transfer learning — to classify skin
lesion images as either **Psoriasis** or **Eczema**. The trained model is
deployed as an interactive **Streamlit** web application that lets a user
upload an image and receive a predicted class with a confidence score.

## 3. Dataset

Two recommended public sources containing both Psoriasis and Eczema labeled
images:

- **Kaggle — Skin Diseases Image Dataset** (ismailpromus):
  https://www.kaggle.com/datasets/ismailpromus/skin-diseases-image-dataset
- **Kaggle — DermNet** (contains "Psoriasis pictures Lichen Planus and
  related diseases" and "Atopic Dermatitis/Eczema" classes):
  https://www.kaggle.com/datasets/shubhamgoel27/dermnet

**Steps to prepare the dataset:**

1. Download either dataset from Kaggle (requires a free Kaggle account/API key).
2. Keep only the Psoriasis and Eczema folders; discard other disease classes.
3. Place them as:
   ```
   raw_data/
   ├── psoriasis/*.jpg
   └── eczema/*.jpg
   ```
4. Run the split helper to build the train/val/test structure automatically:
   ```bash
   python split_dataset.py --raw_dir raw_data --out_dir data --train 0.7 --val 0.15 --test 0.15
   ```

## 5. Training the Model

```bash
python train.py --epochs 15 --fine_tune --fine_tune_epochs 10 --batch_size 32
```

This runs two phases:
1. **Phase 1** — trains only the new classification head, with the
   MobileNetV2 backbone frozen (fast, prevents overfitting on a small dataset).
2. **Phase 2** (`--fine_tune`) — unfreezes the top layers of MobileNetV2 and
   fine-tunes at a lower learning rate for improved accuracy.

Outputs:
- `model/psoriasis_eczema_model.keras` — final trained model
- `model/class_indices.json` — maps class names to output indices
- `outputs/phase1_history.png`, `outputs/phase2_finetune_history.png` — accuracy/loss curves

## 6. Evaluating the Model

```bash
python evaluate.py --model_path model/psoriasis_eczema_model.keras
```

Produces accuracy, precision, recall, F1-score, a confusion matrix, and an
ROC curve with AUC, saved to `outputs/`.

## 7. Running the App Locally

```bash
streamlit run app.py
```

Then open the local URL Streamlit prints (usually `http://localhost:8501`),
upload a skin lesion image, and view the prediction.

## 8. Deploying to Streamlit Community Cloud

1. Push the full repository (including the trained `model/` files) to GitHub.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **New app**, select this repository, branch, and set the main file
   path to `app.py`.
4. Click **Deploy**. Streamlit Cloud will install `requirements.txt`
   automatically and launch the app, giving you a public URL.

> If the trained model file is large (>100 MB), use
> [Git LFS](https://git-lfs.com/) to track it in GitHub.
